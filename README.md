A cat reviews its human like a one-star Yelp critic - refill complaints, an unresolved red dot, unshreddable furniture - written to /output/entry.txt for make.fun's cat-review bounty.

## Run it

```sh
docker run --rm --network none -e MAKEFUN_OUTPUT_DIR=/output -v "$PWD":/bot:ro python:3.13-slim python3 /bot/main.py
```
